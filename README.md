
# Toolbox ORGA
La siguiente aplicacion es un conjunto de herramientas:
- ## Calculadora de cache
  La calculadora resuelve el calculo de distribucion de bits para diferentes funciones de mapeo asociativo y directo en funcion de la informacion brindada por el usuario.
  
- ## Generador de cuadros de cache
  A partir de una distribucion de bits, una funcion de mapeo(asociativo o directo) y una secuencia de direcciones(que pueden estar en binario o en Hexa) se genera una tabla que indica como se distribuyeron los bits y informa si fue un acierto o un fallo.
